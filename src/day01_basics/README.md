## Key learnings
- Java is statically typed, so every variable must have a data type.
- `int` stores whole numbers, while `double` stores decimal numbers.
- `String` stores text, while `char` stores one character.
- `Scanner` reads input from the console.
- `/` performs division and `%` gives the remainder.
- Casting `double` to `int` removes decimals; it does not round.
